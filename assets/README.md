# assets/ — 고정 이미지 자산

캐러셀 맨 뒤에 항상 붙는 **엔드카드(책 홍보 페이지)** 원본을 여기에 둡니다.

## 넣어야 할 파일

| 파일명 | 용도 | 권장 규격 |
|:---|:---|:---|
| `book-promo-endcard.png` | 모든 캐러셀의 마지막 슬라이드 | 정사각(1:1) 또는 4:5, 최소 1080px |

> ⚠️ 이 파일이 없으면 `scripts/make-endcard.js` 가 안내 메시지를 띄우고 종료합니다.
> 이미지는 git 에 커밋해도 되고(용량 작으면), 로컬에만 둬도 됩니다.

## 왜 스크립트를 거치나

인스타 캐러셀은 **한 게시물의 모든 장이 같은 비율**이어야 합니다.
9장이 4:5(1080×1350)인데 엔드카드만 1:1(1080×1080)이면
인스타가 엔드카드를 강제로 잘라내거나 9장 전체를 1:1로 깎습니다.

`make-endcard.js` 는 원본 비율을 유지한 채 4:5 캔버스 중앙에 배치하고
남는 위아래를 브랜드 배경색으로 채워서 **잘림 없이** 맞춥니다.

```bash
node scripts/make-endcard.js --topic 2026-08-04_바이브코딩소식
# → output/2026-08-04_바이브코딩소식/slide-10.png (1080×1350)
```

원본이 이미 4:5 면 레터박스 없이 꽉 차게 들어갑니다.
