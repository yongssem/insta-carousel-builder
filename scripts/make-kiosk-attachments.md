# 무무키오스크 첨부 3종 생성

카페 게시글에 함께 올리는 파일 3개를 만든다.
수치는 `yongssem/mumu-kiosk` 의 `docs/ECONOMY.md` 기준 (일일 상한 60 · 주간 300 ·
교사 재량 학생수×30 · 출석 10 · 자가인증 10 · 교사승인 20 · 보스 50).

```
pip install openpyxl python-docx
python3 scripts/make-kiosk-attachments.py
```

산출물 (`output/mumu-kiosk-promo/첨부/`)

| 파일 | 내용 |
|---|---|
| `학급화폐_미션_상품_목록_예시.xlsx` | 읽어주세요 / 미션 42 / 상점 30 / 교실 특권 12 |
| `무무키오스크_사용설명서_1장.docx` | 준비 3분 · 아이 동선 · 교사 화면 · 칠판 · 안 넣은 것 · 문제 해결 |
| `개인코드_배부카드.docx` | 1~30번, 한 장에 10명 (3쪽) |

⚠️ 앱의 밸런스를 바꾸면 xlsx 도 같이 고쳐야 한다. 글에 첨부된 표와 실제 앱이
어긋나면 따라 하신 선생님이 헷갈린다.
