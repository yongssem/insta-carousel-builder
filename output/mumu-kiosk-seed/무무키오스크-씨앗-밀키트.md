## 30초 동선 (이 앱의 전부)

```
[대기화면]  큰 이모지가 천천히 흔들린다. "화면을 눌러 시작하세요"
    ↓ 아무 곳이나 터치
[번호 선택]  1~30 번호판. 우리 반 인원만 활성
    ↓ 번호 터치
[개인코드]   4자리 숫자판. ●●●● 로 가려짐
    ↓ 4자리 완성 → 자동 전송
[상태창]     이름 · 이모지 · 잔액. [코인 벌기] 버튼 하나
    ↓ 코인 벌기 → 잔액이 올라간다
    ↓ 30초 무입력 → 5초 카운트다운 → 자동 이탈
[대기화면]
```

**되돌아가는 길이 반드시 있어야 합니다.** 공용 태블릿에서 앞사람 화면이
남아 있으면 그게 사고입니다. 자동 이탈은 편의 기능이 아니라 **안전장치**입니다.

## 데이터 설계 (Firestore)

```
classes/{classId}
├─ (doc) name, createdAt
├─ students/{studentId}     name, emoji, balance, lastEarnAt, updatedAt
├─ secrets/{studentId}      passcode              ← 클라이언트 읽기 전면 차단
├─ secrets/attempts         { "s:3": {n, until} } ← 시도 횟수 (여기도 차단)
├─ members/{uid}            studentId             ← 익명 uid ↔ 학생 결속
└─ ledger/{txId}            studentId, delta, before, after, reason, day, at
                            ← append-only. 수정·삭제 금지
```

- `studentId` 는 **번호 문자열** (`"1"` ~ `"30"`)
- `txId` 가 곧 **멱등키**입니다. 같은 키로 두 번 오면 두 번째는 무시됩니다
- `day` 는 KST 기준 `YYYY-MM-DD`. 일일 상한 판정의 근거입니다

## §돈 무결성 6규칙 (이 씨앗의 존재 이유)

원본에서 가장 크게 데인 부분입니다. **구조로 막습니다.**

| # | 규칙 | 어디서 지키나 |
|:---:|---|---|
| 1 | 잔액을 바꾸는 경로는 **`/api/tx.js` 하나뿐.** 클라이언트는 `balance` 쓰기 권한이 없다 | `firestore.rules` |
| 2 | `ledger` 추가 + `balance` 증감을 **한 트랜잭션**으로 | `grantCore()` |
| 3 | 모든 지급에 **멱등키.** 더블탭·재시도로 두 번 안 들어간다 | `grantCore()` |
| 4 | 일일 한도는 `localStorage` 가 아니라 **서버가 ledger 를 세서** 판정 | `sumToday()` |
| 5 | 잔액 **음수 불가.** 부족하면 서버가 거절 | `grantCore()` |
| 6 | **정합성 감사** — `sum(ledger.delta) === balance` 대조 | `audit` op |

> ⚠️ 규칙 4가 왜 중요한가 — 원본은 일일 한도를 `localStorage` 로 셌습니다.
> 브라우저 저장소를 지우면 한도가 초기화돼서 **무한 획득**이 됐습니다.
> 아이들은 이런 걸 서로 알려줍니다.

> ⚠️ 규칙 3이 왜 중요한가 — 태블릿은 터치가 두 번 먹는 일이 흔합니다.
> 멱등키가 없으면 한 번 눌렀는데 두 번 들어갑니다.

## 재현 차단 요소

**코드는 100% 복제됩니다.** 그림 파일은 하나도 안 씁니다 (전부 이모지).

정말로 필요한 것은 **Firebase 프로젝트 하나**뿐입니다. 만드는 순서는 아래
'세상에 내보내기'에 있습니다. 무료 등급으로 충분하고, 카드 등록도 필요 없습니다.

**서버 없이 먼저 보고 싶다면** — `.env` 없이 `npm run dev` 를 돌리면
목(mock) 모드로 뜹니다. 로그인·코인 벌기가 브라우저 메모리에서만 동작하고
화면 흐름은 전부 확인됩니다. 새로고침하면 사라집니다. **고장이 아닙니다.**

> ⚠️ **목 모드는 개인코드를 대조하지 않습니다.** 네 자리이기만 하면 전부 통과합니다.
> 화면 흐름을 보려고 만든 것이라 그렇습니다. **뚫린 게 아니라 아직 서버가 없는 것**이고,
> 실제 대조는 `api/tx.js` 의 `login` op 가 `secrets/{번호}` 와 맞춰 봅니다.
> 시도 횟수 제한도 서버에만 있습니다. **목 모드로 보안을 판단하지 마세요.**

### 📄 firestore.rules

```
rules_version = '2';

// 🔒 이 규칙의 목적은 하나다 — 클라이언트가 잔액을 못 만지게 하는 것.
//
// Admin SDK(api/tx.js)는 규칙을 통과하지 않는다. 그래서 여기서 클라이언트를
// 전부 잠가도 서버는 자유롭게 쓴다. 그게 §돈 무결성 규칙 1의 실체다.
//
// ⚠️ 편의를 위해 students 에 update 를 열지 마세요. 한 번 열면 balance 도 열립니다.
//    "balance 만 빼고 열기"는 규칙으로 표현할 수 있지만, 필드가 늘 때마다 규칙을
//    같이 고쳐야 하고 한 번 빠뜨리면 그게 구멍입니다. 아예 닫는 게 단순하고 안전합니다.

service cloud.firestore {
  match /databases/{database}/documents {

    function signedIn() { return request.auth != null; }

    match /classes/{cid} {
      allow get: if signedIn();
      allow list, write: if false;

      // 학생 문서 — 읽기만. 쓰기는 서버(Admin SDK)만
      match /students/{sid} {
        allow read: if signedIn();
        allow write: if false;
      }

      // 개인코드 — 클라이언트는 읽지도 못한다. 대조는 서버가 한다
      match /secrets/{docId} {
        allow read, write: if false;
      }

      // uid ↔ 학생 결속. 자기 것만 읽고, 만드는 건 서버만
      match /members/{uid} {
        allow read: if signedIn() && request.auth.uid == uid;
        allow write: if false;
      }

      // 원장 — append-only. 클라이언트는 읽기만 하고 절대 못 쓴다
      match /ledger/{txId} {
        allow read: if signedIn();
        allow write: if false;
      }
    }

    match /{document=**} {
      allow read, write: if false;
    }
  }
}
```

```js
// 30초 무입력 → 5초 카운트다운 → 자동 이탈.
//
// 앞사람 계정에 뒷사람이 들어가는 사고를 **구조적으로** 막는다.
// 편의 기능이 아니라 안전장치라서, 끄는 옵션을 두지 않았다.
//
// ⚠️ 15초로 줄이지 마세요. 무엇을 할지 고르는 데 15초는 그냥 지나갑니다.
//    대신 나가기 전 5초를 화면 전체로 크게 알립니다.

import { useEffect, useRef, useState } from 'react'

export const IDLE_MS = 30_000
export const COUNTDOWN = 5

export default function useIdleExit({ onExit, enabled = true }) {
  const [countdown, setCountdown] = useState(null)
  const exitRef = useRef(onExit)
  exitRef.current = onExit

  useEffect(() => {
    if (!enabled) { setCountdown(null); return }

    let idle = null
    let tick = null

    const stop = () => { clearTimeout(idle); clearInterval(tick); tick = null }

    const start = () => {
      stop()
      setCountdown(null)
      idle = setTimeout(() => {
        let left = COUNTDOWN
        setCountdown(left)
        tick = setInterval(() => {
          left -= 1
          if (left <= 0) { stop(); setCountdown(null); exitRef.current?.() }
          else setCountdown(left)
        }, 1000)
      }, IDLE_MS)
    }

    const wake = () => start()
    const events = ['pointerdown', 'keydown', 'touchstart']
    events.forEach((e) => window.addEventListener(e, wake, { passive: true }))
    start()

    return () => {
      stop()
      events.forEach((e) => window.removeEventListener(e, wake))
    }
  }, [enabled])

  return countdown
}
```

### 📄 api/tx.js

```js
// 💰 /api/tx — 잔액을 바꾸는 **유일한 경로** (§돈 무결성 규칙 1)
//
// 클라이언트는 "출석했어요" 까지만 말한다. 몇 코인인지, 오늘 상한에 걸리는지,
// 쿨다운이 남았는지는 **전부 여기서** 계산한다. 금액을 클라이언트가 정하지 못한다.
//
// 인증: Authorization: Bearer <Firebase ID 토큰>
//   학생 op 는 members/{uid} 결속에서 studentId 를 **서버가** 알아낸다.
//   요청 본문의 studentId 는 믿지 않는다 — 믿으면 남의 번호로 쏠 수 있다.
//   login 만 예외이고, 대신 시도 횟수 제한이 걸린다.

import { FieldValue } from 'firebase-admin/firestore'
import { makeCtx, httpErr } from './_ctx.js'
import { REWARDS } from '../src/data/rewards.js'
import { todayKST } from '../src/lib/kst.js'

const classRef = (ctx, cid) => ctx.db.collection('classes').doc(cid)

/* ── 시도 횟수 제한 ─────────────────────────────────
 * 개인코드는 네 자리라 만 번이면 다 뚫린다. 그래서 횟수를 센다.
 * secrets 는 클라이언트 읽기가 전면 차단이라 자기 실패 횟수를 보거나 지울 수 없다.
 */
const ATTEMPT_LIMIT = 5
const LOCK_MS = 30_000

async function guardAttempts(ctx, classId, key) {
  const snap = await classRef(ctx, classId).collection('secrets').doc('attempts').get()
  const rec = snap.exists ? snap.data()?.[key] : null
  if (!rec?.until) return 0
  const left = rec.until - Date.now()
  return left > 0 ? Math.ceil(left / 1000) : 0
}

async function recordAttempt(ctx, classId, key, success) {
  const ref = classRef(ctx, classId).collection('secrets').doc('attempts')
  await ctx.db.runTransaction(async (t) => {
    const snap = await t.get(ref)
    const all = snap.exists ? snap.data() : {}
    const rec = all[key] ?? { n: 0, until: 0 }
    const next = success
      ? { n: 0, until: 0 }
      : { n: rec.n + 1, until: rec.n + 1 >= ATTEMPT_LIMIT ? Date.now() + LOCK_MS : 0 }
    if (!success && next.until) next.n = 0
    t.set(ref, { [key]: next }, { merge: true })
  })
}

/** members 결속에서 studentId 를 알아낸다 */
async function bindStudent(ctx, classId) {
  const snap = await classRef(ctx, classId).collection('members').doc(ctx.uid).get()
  if (!snap.exists) throw httpErr(403, '로그인이 필요해요')
  return String(snap.data().studentId)
}

/** 오늘 번 코인 합 — 규칙 4. localStorage 가 아니라 원장을 센다 */
async function sumToday(ctx, classId, studentId, day) {
  const snap = await classRef(ctx, classId)
    .collection('ledger')
    .where('studentId', '==', studentId)
    .where('day', '==', day)
    .get()
  return snap.docs.reduce((sum, d) => {
    const v = d.data().delta ?? 0
    return v > 0 ? sum + v : sum
  }, 0)
}

/**
 * 지급·차감의 공통 몸통. 6규칙을 여기서 전부 지킨다.
 *
 * ⚠️ Firestore 트랜잭션은 **읽기가 쓰기보다 먼저**여야 한다. 순서를 바꾸지 마세요.
 */
async function grantCore(ctx, { classId, studentId, reason, label, coin, key, cooldownMs = 0 }) {
  if (!key) throw httpErr(400, '멱등키 없이 지급할 수 없다 (규칙 3)')

  const day = todayKST()

  // 규칙 4 — 일일 상한은 서버가 원장을 세서 판정한다
  let granted = coin
  let capped = false
  if (coin > 0) {
    const earned = await sumToday(ctx, classId, studentId, day)
    const room = Math.max(0, REWARDS.dailyCap - earned)
    granted = Math.min(coin, room)
    capped = granted < coin
  }

  const ledgerRef = classRef(ctx, classId).collection('ledger').doc(key)
  const studentRef = classRef(ctx, classId).collection('students').doc(studentId)

  const out = await ctx.db.runTransaction(async (t) => {
    // ── 읽기 먼저 ──
    // 규칙 3 — 멱등키 검사를 트랜잭션 **안**에서. 동시 더블탭도 못 뚫는다
    const dup = await t.get(ledgerRef)
    const sSnap = await t.get(studentRef)

    if (dup.exists) return { duplicate: true, balance: dup.data().after ?? 0 }
    if (!sSnap.exists) throw httpErr(404, '학생 문서가 없어요')
    const s = sSnap.data()

    if (cooldownMs && s.lastEarnAt) {
      const left = cooldownMs - (Date.now() - s.lastEarnAt)
      if (left > 0) throw httpErr(429, `${Math.ceil(left / 1000)}초만 기다려 주세요`)
    }

    const before = s.balance ?? 0
    const after = before + granted
    // 규칙 5 — 음수 불가
    if (after < 0) throw httpErr(400, '잔액이 부족해요')

    // ── 쓰기 ──
    // 규칙 2 — 원장 추가와 잔액 증감을 같은 트랜잭션에서
    t.set(ledgerRef, {
      studentId, delta: granted, before, after,
      reason, label: label ?? reason, day,
      at: FieldValue.serverTimestamp(),
    })
    t.update(studentRef, {
      balance: FieldValue.increment(granted),
      lastEarnAt: Date.now(),
      updatedAt: FieldValue.serverTimestamp(),
    })

    return { duplicate: false, balance: after }
  })

  return {
    ok: true,
    duplicate: out.duplicate,
    granted: out.duplicate ? 0 : granted,
    capped: out.duplicate ? false : capped,
    balance: out.balance,
    label: label ?? reason,
  }
}

const OPS = {
  async ping() {
    return { ok: true, server: true }
  },

  /** 개인코드 로그인 — 결속을 만든다. 유일하게 studentId 를 본문에서 받는 op */
  async login(ctx, classId, body) {
    const sid = String(body.studentId ?? '')
    const code = String(body.code ?? '')
    if (!sid || !/^\d{4}$/.test(code)) return { ok: false }

    const wait = await guardAttempts(ctx, classId, `s:${sid}`)
    if (wait) return { ok: false, locked: true, wait }

    const secret = await classRef(ctx, classId).collection('secrets').doc(sid).get()
    const ok = secret.exists && String(secret.data().passcode) === code
    await recordAttempt(ctx, classId, `s:${sid}`, ok)
    if (!ok) return { ok: false }

    await classRef(ctx, classId).collection('members').doc(ctx.uid).set({
      studentId: sid,
      at: FieldValue.serverTimestamp(),
    })
    return { ok: true }
  },

  /** 내 상태 — 상태창이 부른다 */
  async me(ctx, classId) {
    const sid = await bindStudent(ctx, classId)
    const snap = await classRef(ctx, classId).collection('students').doc(sid).get()
    if (!snap.exists) throw httpErr(404, '학생 문서가 없어요')
    const s = snap.data()
    return {
      ok: true,
      student: { id: sid, name: s.name ?? `${sid}번`, emoji: s.emoji ?? '🙂', balance: s.balance ?? 0 },
    }
  },

  /** 코인 벌기 */
  async earn(ctx, classId, body) {
    const sid = await bindStudent(ctx, classId)
    const action = String(body.action ?? '')
    const r = REWARDS.actions[action]
    if (!r) throw httpErr(400, '없는 활동이에요')

    // 하루 한 번짜리는 멱등키에 날짜가 들어간다 — 두 번째부터는 자동으로 중복 처리
    const key = r.oncePerDay ? `${action}:${sid}:${todayKST()}` : String(body.key ?? '')

    return grantCore(ctx, {
      classId, studentId: sid,
      reason: action, label: r.label, coin: r.coin,
      key, cooldownMs: r.cooldownMs ?? 0,
    })
  },

  /** 규칙 6 — 정합성 감사. sum(ledger.delta) === balance 인지 대조한다 */
  async audit(ctx, classId) {
    const [students, ledger] = await Promise.all([
      classRef(ctx, classId).collection('students').get(),
      classRef(ctx, classId).collection('ledger').get(),
    ])
    const sums = {}
    ledger.docs.forEach((d) => {
      const { studentId, delta = 0 } = d.data()
      sums[studentId] = (sums[studentId] ?? 0) + delta
    })
    const bad = []
    students.docs.forEach((d) => {
      const balance = d.data().balance ?? 0
      const sum = sums[d.id] ?? 0
      if (balance !== sum) bad.push({ studentId: d.id, balance, sum })
    })
    return { ok: bad.length === 0, checked: students.size, mismatched: bad }
  },
}

export async function handleOp(ctx, body) {
  const op = String(body.op ?? '')
  const classId = String(body.classId ?? '')
  const fn = OPS[op]
  if (!fn) throw httpErr(400, '없는 요청이에요')
  if (op !== 'ping' && !classId) throw httpErr(400, '학급이 없어요')
  return fn(ctx, classId, body)
}

export default async function handler(req, res) {
  if (req.method !== 'POST') return res.status(405).json({ error: 'POST 만 받아요' })

  const ctx = makeCtx()
  if (ctx === 'bad') return res.status(500).json({ error: '서비스 계정 형식이 잘못됐어요' })
  if (!ctx) return res.status(501).json({ error: '서버가 아직 설정되지 않았어요' })

  const body = req.body ?? {}
  if (body.op !== 'ping') {
    const m = /^Bearer (.+)$/.exec(req.headers.authorization ?? '')
    if (!m) return res.status(401).json({ error: '로그인이 필요해요' })
    try {
      const decoded = await ctx.adminAuth.verifyIdToken(m[1])
      ctx.uid = decoded.uid
    } catch {
      return res.status(401).json({ error: '로그인이 만료됐어요' })
    }
  }

  try {
    const out = await handleOp(ctx, body)
    return res.status(200).json(out)
  } catch (e) {
    return res.status(e.status ?? 500).json({ error: e.message ?? '알 수 없는 오류' })
  }
}
```

```jsx
// 번호 + 개인코드 4자리.
//
// ⚠️ 개인코드를 화면에 그대로 보여주지 마세요. 교실 앞 공용 태블릿이라
//    뒷사람이 다 봅니다. ● 로 가립니다.
// ⚠️ 틀렸을 때 "몇 번째 자리가 틀렸다" 같은 힌트를 주지 마세요.

import { useState } from 'react'
import { callTx } from '../lib/api.js'

const NUMBERS = Array.from({ length: 30 }, (_, i) => i + 1)

export default function CodePad({ onDone, onCancel }) {
  const [sid, setSid] = useState(null)
  const [code, setCode] = useState('')
  const [err, setErr] = useState('')
  const [busy, setBusy] = useState(false)

  async function submit(next) {
    setBusy(true)
    setErr('')
    try {
      const r = await callTx('login', { studentId: String(sid), code: next })
      if (r.ok) { onDone(); return }
      setErr(r.locked ? `잠시 잠겼어요. ${r.wait}초 뒤에 다시 해주세요` : '코드가 맞지 않아요')
    } catch (e) {
      setErr(e.message)
    }
    setCode('')
    setBusy(false)
  }

  function press(d) {
    if (busy || code.length >= 4) return
    const next = code + d
    setCode(next)
    if (next.length === 4) submit(next)
  }

  if (sid === null) {
    return (
      <div className="screen">
        <div className="title">몇 번이에요?</div>
        <div className="grid n5">
          {NUMBERS.map((n) => (
            <button key={n} onClick={() => setSid(n)}>{n}</button>
          ))}
        </div>
        <div className="grid">
          <button className="ghost" onClick={onCancel}>뒤로</button>
        </div>
      </div>
    )
  }

  return (
    <div className="screen">
      <div className="title">{sid}번, 개인코드 4자리</div>
      <div className="dots">{'●'.repeat(code.length)}</div>
      <div className="grid n3">
        {[1,2,3,4,5,6,7,8,9].map((d) => (
          <button key={d} disabled={busy} onClick={() => press(String(d))}>{d}</button>
        ))}
        <button className="ghost" disabled={busy} onClick={() => setCode('')}>지움</button>
        <button disabled={busy} onClick={() => press('0')}>0</button>
        <button className="ghost" onClick={() => { setSid(null); setCode(''); setErr('') }}>번호</button>
      </div>
      <div className="err">{err}</div>
    </div>
  )
}
```

```jsx
// 상태창 + 코인 벌기.
//
// ⚠️ 잔액을 화면에서 직접 계산하지 마세요. 서버가 돌려준 balance 만 씁니다.
//    화면에서 더하면 상한에 걸렸을 때 실제와 어긋납니다.

import { useEffect, useState } from 'react'
import { callTx, newKey } from '../lib/api.js'
import { REWARDS } from '../data/rewards.js'

export default function Status({ onExit }) {
  const [me, setMe] = useState(null)
  const [msg, setMsg] = useState('')
  const [busy, setBusy] = useState(false)

  useEffect(() => {
    callTx('me').then((r) => setMe(r.student)).catch((e) => setMsg(e.message))
  }, [])

  async function earn(action) {
    if (busy) return
    setBusy(true)
    setMsg('')
    try {
      const r = REWARDS.actions[action]
      const out = await callTx('earn', {
        action,
        key: r.oncePerDay ? undefined : newKey(action),
      })
      setMe((m) => ({ ...m, balance: out.balance }))
      if (out.duplicate) setMsg('오늘은 이미 했어요')
      else if (out.capped) setMsg(`오늘 상한이라 ${out.granted}코인만 받았어요`)
      else setMsg(`${out.label} +${out.granted}`)
    } catch (e) {
      setMsg(e.message)
    }
    setBusy(false)
  }

  if (!me) return <div className="screen"><div className="sub">{msg || '불러오는 중...'}</div></div>

  return (
    <div className="screen">
      <div className="big">{me.emoji}</div>
      <div className="title">{me.name}</div>
      <div className="card">
        <div className="sub">가진 코인</div>
        <div className="balance">{me.balance}</div>
      </div>
      <div className="grid">
        {Object.entries(REWARDS.actions).map(([id, r]) => (
          <button key={id} disabled={busy} onClick={() => earn(id)}>
            {r.label} +{r.coin}
          </button>
        ))}
        <button className="ghost" onClick={onExit}>완료하고 나가기</button>
      </div>
      <div className="err">{msg}</div>
```

## 함정 노트 (실제 겪은 것)

### ① 클라이언트에서 잔액을 고칠 수 있으면 그날로 끝난다

원본에서 제일 크게 데인 부분입니다. 편해 보여서 `students` 에 `update` 를 열면,
그 순간 `balance` 도 열립니다. **규칙에서 아예 닫고 서버만 쓰게** 하세요.

"balance 만 빼고 열기"도 규칙으로 쓸 수는 있지만, 필드가 늘 때마다 규칙을 같이
고쳐야 하고 한 번 빠뜨리면 그게 구멍입니다.

### ② 일일 한도를 localStorage 로 세면 무한 획득이 된다

원본이 그랬습니다. 브라우저 저장소를 지우면 한도가 초기화됐습니다.
**아이들은 이런 걸 서로 알려줍니다.** 한도는 반드시 서버가 원장을 세서 판정합니다.

### ③ 태블릿은 터치가 두 번 먹는다

멱등키가 없으면 한 번 눌렀는데 두 번 들어갑니다. 그리고 이건 재현이 어려워서
"가끔 두 배로 들어온대요"라는 제보로만 옵니다. **모든 지급에 멱등키를 붙이세요.**

### ④ 요청 본문의 studentId 를 믿으면 남의 번호로 쏠 수 있다

`{ studentId: 7, action: 'attend' }` 를 그대로 처리하면, 개발자도구를 열 줄 아는
아이가 7번에게 코인을 넣거나 뺄 수 있습니다. **서버가 members 결속에서 알아냅니다.**

### ⑤ Firestore 트랜잭션은 읽기가 쓰기보다 먼저다

`t.get()` 을 `t.set()` 뒤에 두면 런타임 오류가 납니다. `grantCore()` 의
읽기 두 개가 위에 몰려 있는 건 그 때문입니다. 순서를 바꾸지 마세요.

### ⑥ 로그인 상태를 localStorage 에 저장하면 앞사람 계정이 남는다

공용 태블릿에서 제일 잘 나는 사고입니다. 이 씨앗은 세션을 **메모리에만** 둡니다.
개인 태블릿으로 쓰실 거면 그때 저장을 켜세요 — 공용에서는 절대 안 됩니다.

### ⑦ 대기화면에서 데이터를 부르면 할당량이 녹는다

교실 앞에 하루 종일 켜져 있는 화면입니다. 5초마다 뭔가를 부르면 하루 1만 회가
넘습니다. 대기화면은 **아무것도 부르지 않습니다.**

이 앱은 **C. 서버형**입니다 (빌드 + 환경변수 + 서버 함수).

### [0단계] 올리기 전 안전 점검 ← 반드시 먼저

```
□ .env 가 .gitignore 에 있는가?
□ serviceAccount.json 이 폴더에 굴러다니지 않는가?
□ 코드 안에 서비스 계정 JSON 이 직접 박혀 있지 않은가?
□ node_modules / dist 가 .gitignore 에 있는가?
□ 학생 실명이 들어간 파일이 없는가?
```

> ⚠️ 한 번 올라간 키는 지워도 기록에 남습니다. 실수로 올렸다면 지우는 것으로
> 끝내지 말고 Firebase 콘솔에서 **재발급**하세요.

### [1단계] Firebase 프로젝트

```
1. console.firebase.google.com → 프로젝트 만들기 (애널리틱스 꺼도 됨)
2. 빌드 → Firestore Database → 데이터베이스 만들기 → 프로덕션 모드 → asia-northeast3(서울)
3. 빌드 → Authentication → 시작하기 → 익명 사용 설정
4. 프로젝트 설정 → 내 앱 → 웹앱 추가 → 설정값을 .env 에 옮긴다
5. 프로젝트 설정 → 서비스 계정 → 새 비공개 키 생성 → JSON 파일 다운로드
```

### [2단계] 규칙 올리기 ← 이걸 빠뜨리면 잠금이 없는 것과 같다

Firebase 콘솔 → Firestore → 규칙 탭에 `firestore.rules` 내용을 붙이고 **게시**합니다.

> ⚠️ 프로덕션 모드로 만들었어도 기본 규칙은 이 앱에 맞지 않습니다. 반드시 교체하세요.

```

```

출력된 코드표를 인쇄해서 나눠 주세요. **선생님만 보관합니다.**

### [4단계] GitHub → Vercel

```
1. GitHub 저장소 만들고 올린다 (공개해도 됩니다 — 키는 안 들어 있으니)

4. Environment Variables 에 넣는다
   · VITE_FB_API_KEY, VITE_FB_AUTH_DOMAIN, VITE_FB_PROJECT_ID, VITE_CLASS_ID
   · FIREBASE_SERVICE_ACCOUNT ← JSON 통째로 (줄바꿈 그대로 붙여도 됩니다)
```
