클로드 코드, 2주 사이 '자동 실행' 6개 잠갔다

앤트로픽이 지난 7월 17일부터 8월 4일까지 약 2주 동안 코딩 도구 클로드 코드에 제한 장치 6개를 연달아 추가했다. 항목별로는 작은 수정이라 따로 알려지지 않았지만, 묶어 보면 방향이 하나다. 클로드가 사용자의 지시 없이 스스로 작업을 벌이는 경로를 막는 쪽이다.

가장 먼저 적용된 것은 호출 횟수 상한이다. 7월 17일 배포된 v2.1.213부터 세션당 웹 검색이 200회, 서브에이전트 소환이 200회로 묶였다. 그동안은 상한이 없어 클로드가 검색을 반복하다 사용량을 소진하는 일이 있었다.

이틀 뒤인 7월 19일 v2.1.215에서는 /verify와 /code-review의 자동 실행이 중단됐다. 두 기능이 사라진 것은 아니고, 사용자가 직접 부를 때만 작동하는 방식으로 바뀌었다.

7월 21일 v2.1.217에서는 동시에 실행되는 서브에이전트가 20개로 제한됐다. 하루 뒤 v2.1.218에서는 /deep-research가 수동 호출 시에만 시작하도록 변경됐다.

가장 최근인 8월 4일 v2.1.222에서는 격리된 작업 공간에서 실행된 세션이 원본 폴더에 파괴적인 git 명령을 실행할 수 있던 문제가 수정됐다. 안전하게 실험하라고 만들어둔 격리 방식에 남아 있던 구멍이었다.

적용 범위는 전체 사용자다. 요금제나 지역에 따른 제한은 없고, 클로드 코드를 최신 버전으로 업데이트하면 그대로 반영된다. 따로 설정할 항목은 없다.

체감이 가장 큰 쪽은 사용량 한도를 자주 소진하던 사용자다. 검색과 서브에이전트 호출에 천장이 생기면서, 클로드가 혼자 반복 작업을 돌다 주간 한도를 다 쓰는 상황이 구조적으로 차단됐다.

다만 업데이트 이후 /verify나 /deep-research가 켜지지 않는 것을 두고 기능이 없어졌다고 오해할 수 있다. 두 기능 모두 그대로 있으며, 직접 호출하면 동일하게 작동한다.

이 내용은 2026년 8월 4일 기준 클로드 코드 공식 체인지로그(https://code.claude.com/docs/en/changelog)에서 v2.1.213부터 v2.1.222까지 항목을 직접 대조해 확인했다.
