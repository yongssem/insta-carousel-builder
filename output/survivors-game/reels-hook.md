## 먼저 정한 것 두 가지

### 1) 후킹 4초는 실제 화면 녹화로 갑니다

AI 생성 영상을 후킹에 쓰면 안 됩니다. 4초에 본 화면과 실제 게임이 다르면
넘어온 사람이 바로 이탈하고, 그게 반복되면 계정 도달이 깎입니다.
**AI 영상은 게임 화면이 아닌 컷(배경·전환·손 이미지)에만** 쓰세요.

### 2) 소리 없이도 이해돼야 합니다

릴스도 음소거로 시작되는 경우가 많습니다.
**4초 안의 모든 정보는 자막으로 화면에 있어야** 합니다. 나레이션은 보조입니다.

### ⚠️ 이름 주의 (EP.05 와 동일)

"뱀서류 / 뱀서라이크"는 장르를 부르는 말이라 **설명에는 써도 됩니다.**
다만 **게임 이름에 넣지 마세요.** Vampire Survivors 는 실제 상품명입니다.
게임 이름은 완전히 분리해서 짓습니다 (예: `무무서바이벌`, `쉬는시간 생존기`).

## 후킹 안 4개

### ⭐ A안 — 증거 → 방법 → 공개 약속 (1순위)

#### 초안 A0 가 약했던 이유

처음 잡았던 안은 `적 3마리 → 적 300마리 → 코딩은 0줄` 이었습니다. 세 군데가 약합니다.

1. **약속이 없다.** 볼거리만 있고 시청자가 받아갈 게 없습니다. 스크롤은 멈추지만 남지 않습니다
2. **마지막 자막이 자랑이다.** "코딩은 0줄"은 내 이야기지 시청자 이득이 아닙니다
3. **저장할 이유가 없다.** 저장은 "나중에 쓸 것"에만 눌립니다. 공개 약속이 저장을 만듭니다

#### 고친 구조

**증거(스펙터클) → 방법 노출 → 공개 약속.**
핵심은 **공개할 물건을 4초 안에 보여주는 것**입니다.
"다 알려드릴게요"만 하면 누구나 하는 말이고, **프롬프트가 화면에 뜨는 순간 약속이 증거로 바뀝니다.**

| 시간 | 화면 | 자막 |
|:---|:---|:---|
| 0.0–1.3초 | 적이 화면을 뒤덮은 상태에서 **시작**. 자동 공격 난사 | `이거 만드는 법` |
| 1.3–2.3초 | 화면이 반으로 갈라지며 오른쪽에 프롬프트 3줄이 뜸 | `제가 쓴 건 이게 다예요` |
| 2.3–4.0초 | 프롬프트가 화면을 채움. 게임은 뒤에서 계속 돌아감 | `그대로 다 공개합니다` |

- **가장 센 장면으로 시작합니다.** 한산한 화면으로 여는 건 0.5초도 아깝습니다.
  "적 3마리 → 300마리" 대비는 후킹이 아니라 **본문(4초 이후)에서** 쓰세요
- **프롬프트를 흐리게 처리하지 마세요.** 가리면 "낚시"가 되고 댓글로 지적당합니다.
  읽히게 두는 게 이 후킹의 전부입니다
- 뒤에서 게임이 계속 돌아가야 합니다. 정지 화면이 되면 이탈합니다

#### 변형 A-2 — 장벽 제거형

숫자를 이득 쪽으로 돌립니다. `코딩은 0줄`을 자랑이 아니라 **"너도 된다"** 로 바꾸는 방식입니다.

| 시간 | 화면 | 자막 |
|:---|:---|:---|
| 0.0–1.2초 | 적 떼가 몰려오는 화면 | `코딩 0줄` |
| 1.2–2.0초 | 같은 화면, 숫자만 하나 더 찍힘 | `추가 결제 0원` |
| 2.0–2.8초 | 하나 더 | `20분` |
| 2.8–4.0초 | 프롬프트 화면으로 전환 | `만드는 법 전부 풀어요` |

- 세 숫자는 **실제 값만** 쓰세요. 20분이 아니면 20분이라고 쓰지 마세요

#### 변형 A-3 — 되묻기형 (댓글 유도)

| 시간 | 화면 | 자막 |
|:---|:---|:---|
| 0.0–1.5초 | 적 떼 화면 | `이런 게임, 교사가 만들 수 있을까요` |
| 1.5–2.5초 | 같은 화면 유지 | `됩니다` |
| 2.5–4.0초 | 프롬프트 등장 | `순서 하나도 안 빼고 알려드릴게요` |

- 질문형은 도달보다 **댓글**이 붙습니다. 계정을 키우는 단계라면 이쪽도 좋습니다

#### ⚠️ 약속했으면 지켜야 합니다

"다 공개"라고 해놓고 본문에서 일부만 보여주면 **다음 릴스 도달이 깎입니다.**
4초에서 약속한 건 릴스 안에서 전부 보여주세요. 프로필 링크로 빼지 마세요.
링크로 빼는 순간 "결국 팔이였네"가 되고, 그게 이 계정이 제일 피해야 할 인상입니다.

#### 이 후킹이 A0 보다 나은 이유

| | A0 (초안) | A (수정) |
|:---|:---|:---|
| 4초에 준 것 | 구경거리 | 구경거리 + 받아갈 것 |
| 마지막 자막 | 내 자랑 | 시청자에게 하는 약속 |
| 저장 동기 | 없음 | 프롬프트를 나중에 쓰려고 |
| 이탈 지점 | 4초 뒤 바로 | 프롬프트 다 볼 때까지 |

### B안 — 아이들 반응 먼저 (교사 계정에 가장 잘 맞음)

저장·공유는 이쪽이 강합니다. 게임보다 **교실**이 주인공입니다.

| 시간 | 화면 | 자막 |
|:---|:---|:---|
| 0.0–1.4초 | 태블릿 여러 대에 같은 게임. 아이들 손만 (얼굴 금지) | `쉬는 시간에 하나 띄웠더니` |
| 1.4–2.4초 | 한 명이 화면 가리키며 몸이 앞으로 쏠림 | `— 선생님이 만든 거예요?` |
| 2.4–4.0초 | 게임 화면 클로즈업으로 전환 | `20분 걸렸습니다` |

- **초상권**: 얼굴·명찰·교실 특정 요소 안 나오게. 손과 화면만
- 학교에 따라 촬영 동의가 필요합니다. 확인하고 찍으세요

### C안 — 한 줄이 게임이 된다 (과정 압축형)

"코딩 안 한다"를 말로 하지 않고 **보여주는** 방식입니다.

| 시간 | 화면 | 자막 |
|:---|:---|:---|
| 0.0–1.6초 | 까만 터미널. 한글 문장이 타이핑됨 | (타이핑 자체가 자막) |
| 1.6–2.0초 | 엔터 치는 손가락 | — |
| 2.0–4.0초 | 컷 전환 → 완성된 게임이 돌아감 | `이게 전부입니다` |

- 타이핑 문장: `적이 몰려오고 자동으로 공격하는 게임 만들어줘`
- 타이핑은 실제보다 2~3배 빠르게. 1.6초를 넘기면 이탈합니다

### D안 — 실패부터 보여주기 (신뢰형)

성공만 보여주는 계정과 갈리는 자리입니다. 도달은 A보다 낮고 **댓글은 더 붙습니다.**

| 시간 | 화면 | 자막 |
|:---|:---|:---|
| 0.0–1.8초 | 게임이 이상함. 적이 안 나오거나 캐릭터가 안 움직임 | `이거 왜 안 되지` |
| 1.8–2.6초 | 문장 한 줄 추가로 입력 | `한 줄 빠졌더라고요` |
| 2.6–4.0초 | 정상 작동. 적이 쏟아짐 | `고장이 아니었습니다` |

## 문구 제안

### 4초 안에 쓸 자막 (짧을수록 좋음, 한 컷에 9자 이내)

**공개 약속 (A안 계열 — 1순위로 쓰세요)**
- `그대로 다 공개합니다`
- `제가 쓴 건 이게 다예요`
- `만드는 법 전부 풀어요`
- `순서 하나도 안 빼고`
- `이 세 줄이 전부입니다`
- `따라 하시라고 다 보여드려요`

> 약속 문구는 **구체적인 물건과 붙어야** 힘이 생깁니다.
> `비법 대공개` 같은 건 금칙어입니다(`banned-words.json`). 무엇을 공개하는지가 없으면 어그로가 됩니다.
> ❌ `비법 대공개` → ✅ `프롬프트 3줄 그대로 공개`

**결과 강조**
- `코딩은 0줄`
- `적 300마리`
- `20분 걸렸습니다`
- `이게 전부입니다`

**교실 맥락**
- `쉬는 시간에 띄웠더니`
- `우리 반 게임입니다`
- `설치 없이 링크만`
- `선생님이 만든 거예요?`

**과정 강조**
- `말로만 시켰습니다`
- `한 줄 빠졌더라고요`
- `고장이 아니었습니다`
- `안 되면 다시 말하면 됩니다`

### 첫 댓글 / 캡션 첫 줄 (후킹 문구와 다르게)

- 적이 몰려오는 게임인데, 정작 제가 한 건 문장 세 개였습니다.
- 아이들이 제일 오래 붙어 있던 게 제가 20분 만에 만든 거였습니다.
- 처음엔 적이 아예 안 나왔습니다. 고장인 줄 알았는데 아니었어요.

### ❌ 쓰지 말 것

`banned-words.json` 기준입니다.

| 금지 | 이유 |
|:---|:---|
| 미친 꿀팁 · 레전드 · 대박 · 게임 체인저 | 과장 클리셰. 계정 톤과 안 맞음 |
| 안녕하세요 · 오늘은 · 여러분 | 4초를 버리는 인트로 |
| 충격 · 소름 · 이것만 보세요 | 어그로. 도달은 오르고 신뢰는 내려감 |
| 개발자도 놀란 | 확인 불가한 주장 |

## "선생님이 캐릭터가 되는" 연출 — 어떻게 할 것인가

### ❌ 하지 말 것: 탕탕특공대 캐릭터로 분한 영상

`탕탕특공대`는 Habby 의 Survivor.io 한국 서비스명입니다.
**장르(뱀서라이크)는 자유지만 특정 게임의 캐릭터 디자인을 차용하는 건 다릅니다.**
릴스는 캐러셀보다 도달이 넓어 걸릴 확률도 높습니다.

### ❌ 후킹 4초에 실사 시네마틱을 끼우는 것도 반대

1. **4초에 세 가지가 안 들어갑니다.** 실사 컷 + 게임 화면 + 프롬프트를 다 넣으면
   셋 다 스쳐 지나갑니다. A안의 핵심인 "프롬프트를 4초 안에 보여주기"가 죽습니다
2. **기대 배반.** 실사 액션을 보고 들어왔는데 결과물이 도트 게임이면 그 격차가 이탈이 됩니다
3. **원칙 충돌.** 이 문서 맨 앞에서 "게임 화면에 AI 생성 영상 쓰지 않기"를 정했는데,
   좀비 처치 영상은 사실상 게임 장면입니다

### ⭐ 대신: 게임 캐릭터를 실제로 선생님으로 만듭니다

발상 자체는 좋습니다. **영상으로 흉내 내지 말고 진짜로 구현하면** 됩니다.

- 플레이어 캐릭터 스프라이트를 **바이브용샘 치비**로 교체
- `assets/characters/` 에 이미 같은 화풍의 3D 치비 5종(dev·maker·teacher·scholar·fairy)이 있습니다.
  같은 `common_style` 로 한 개만 더 생성하면 화풍이 그대로 이어집니다
- 게임 배경 위에 얹어야 하므로 **배경은 크림색(#F3EEE2)이 아니라 투명**으로 뽑아야 합니다
  (캐러셀용 캐릭터와 다른 점 — 그대로 쓰면 사각형 자국이 남습니다)

이렇게 하면,

| | 시네마틱 영상 | 캐릭터 교체 |
|:---|:---|:---|
| 상표 위험 | 있음 | 없음 |
| 실제 결과물과 일치 | ✗ | ✓ |
| 4초 예산 소모 | 큼 | 0 (게임 화면이 곧 그 화면) |
| 재사용 | 이 릴스 한 번 | 앞으로 만드는 모든 게임에 |

**후킹 0~1.3초에 나오는 게임 화면에 이미 선생님이 들어 있게 됩니다.**
따로 컷을 쓸 필요가 없어집니다.

### 적은 좀비 말고 다른 걸 권합니다

교사 계정입니다. 초등 아이들과 학부모가 봅니다.
**좀비를 처치하는 화면은 톤이 안 맞을 수 있습니다.**

- 보라색 말랑한 덩어리(슬라임/블롭) — 이미 무무점프 적이 이 계열입니다
- 종이 뭉치, 밀린 서류, 알림장 — 교사 정서에 꽂히는 쪽
- "쌓인 업무"를 적으로 두면 **공감 소재**가 되면서 댓글이 붙습니다

마지막 안은 이 계정에서 꽤 셉니다. 게임이 곧 농담이 됩니다.

## AI 영상을 쓴다면 (게임 화면 외 컷 한정)

전환컷이나 배경으로만. **게임 플레이 장면은 절대 생성하지 마세요.**

```
Close-up of hands typing on a laptop keyboard in a warm, sunlit classroom.
Shallow depth of field, screen glow reflected on the desk.
Static shot, no camera movement. 2 seconds, no text overlay.
```

```
Overhead shot of three tablets on a wooden desk, screens glowing,
children's hands reaching in from the edges of frame. Faces not visible.
Soft natural light. Slow push-in. 3 seconds.
```

그래도 "선생님이 싸우는" 컷을 꼭 쓰고 싶다면, **실사 대신 치비 화풍으로** 뽑으세요.
기존 캐릭터 자산과 화풍이 이어져서 광고 소재처럼 붕 뜨지 않습니다.
**넣을 자리는 후킹이 아니라 릴스 마지막 2초(아웃트로)** 입니다.

```
3D chibi character with an oversized head and small rounded body, soft matte
clay-like material, wearing a navy zip-up hoodie, standing in a simple stylized
field. Soft purple blob creatures slowly approach from all sides. The character
calmly raises one hand and a gentle ring of light pushes the blobs away.
Warm soft studio lighting, soft drop shadow, friendly and playful, not scary.
Static camera, 3 seconds, no text, no logos.
```

- `no logos` 를 넣은 건 모델이 임의로 상표 비슷한 걸 그려 넣는 걸 막기 위해서입니다
- 좀비가 아니라 `soft purple blob creatures` 로 잡았습니다. 교사 계정 톤에 맞고 IP 위험도 없습니다

두 컷 모두 **얼굴이 들어가지 않게** 프롬프트에 명시했습니다.
AI 생성 영상을 쓰면 캡션이나 화면에 그 사실을 밝히세요.
