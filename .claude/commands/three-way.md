## 반드시 먼저 읽기

1. `knowledge/patterns/3way-repurpose.md` — **채널별 역할 분담 (핵심)**
2. `knowledge/sources.md` — 라이트 소재(툴 업데이트) 출처 + 선별 기준
3. `knowledge/brand-facts.md` — 표기 고정값, 인용 가능 수치
4. `knowledge/banned-words.json` — 금칙어, swipe 승인 목록

## 소재 범위

**주력은 라이트 소재**입니다 — 구독료 변경 · 새 모델 출시 · 새 기능.
주요 툴: **클로드(코드) · 러버블 · Codex · Gemini**.

무겁고 추상적인 주제(AI 윤리, 거대 담론)는 블로그에 쓸 경험이 안 나오므로
3way 소재로는 부적합합니다. 가끔만 섞으세요.

⭐ **소재를 정하기 전에 `sources.md` 의 "교무실 옆자리 테스트"를 먼저 통과시키세요.**
슬래시 명령어·버전 번호·토큰 단가·서브에이전트 같은 개발자 용어가 소재의 뼈대라면
**그 소재는 버립니다.** 라이트 소재라도 전문적일 수 있습니다.
돈·새로 되는 일·학교 혜택·시간 절약처럼 **안 써본 교사도 바로 이해되는 각도**로 잡으세요.

## 사실 확인 (생략 금지)

- 기능·요금은 **공식 체인지로그/요금 페이지 원문**에서 확인
- 요금은 국가·시점별로 다르므로 **확인 날짜를 반드시 기록**하고 산출물에 시점 명시
- 확인 못 한 수치는 **쓰지 않습니다** (추정치 금지)

⚠️ **요금 페이지에는 월간/연간 토글이 있습니다.** 어느 탭의 값인지 확인하고
산출물에 **"월간 기준"을 반드시 병기**하세요. 기본 선택이 연간인 페이지가 있어서,
그대로 옮기면 실제 월 청구액보다 싸게 적힙니다.
실제 사고: 클로드 Pro를 연간 탭 값 $18로 표기 → 월간 $22 가 정답이었음.
부가세 포함 여부도 페이지에 적혀 있으면 같이 옮깁니다.

## 산출물

`output/<topic>/` 아래에:

### 1) `news.md` — 무궁무진 클래스 커뮤니티 AI뉴스 (먼저)
- 400~800자. 첫 문장에 결론. **회원 대상이라 자기소개·후킹 불필요**
- 무엇이 · 언제부터 · 얼마에 · 누가 쓸 수 있나
- **공식 링크를 본문에 직접 걸기** — 링크가 클릭되는 유일한 채널입니다
- 요금·기능은 확인 날짜 병기
- 긴 해석은 넘기되 한 줄 코멘트는 허용
- **마지막은 질문으로** (커뮤니티는 댓글이 생명)

⭐ **형식: 마크다운 금지, 신문 기사체.** `#` 제목기호 · `**굵게**` · 표 · 불릿 · `---`
전부 쓰지 마세요. 제목은 첫 줄에 한 줄, 본문은 문단으로 잇고 `~했다` 체로 씁니다.
링크는 주소를 그대로 적습니다. 마지막 댓글 유도 한 줄만 존댓말로 돌아옵니다.
자세한 이유와 대응표는 `3way-repurpose.md` 의 "형식 — 마크다운 금지" 절 참고.

### 2) `templates/slides.v5.<topic>.json` → 캐러셀
- 사실은 1~2장으로 압축, 나머지는 **교실 번역**
- 만들고 나서 바로 실행:
  ```bash
  node scripts/make-carousel.mjs --data templates/slides.v5.<topic>.json --topic <topic>
  ```
- `caption.md` 도 함께 작성 (캡션 첫 줄은 뉴스 제목과 **다르게**)

### 3) `blog.md` — 블로그 (마지막)
- **"직접 써봤다"가 없으면 초안만 만들고 발행 보류**로 표시
- 구성: 뭐가 바뀌었나(짧게) → 직접 해본 과정 → 안 되던 것 → 교실 적용 → 결론
- 스크린샷 자리를 `> [스크린샷: 설명]` 으로 표시해두기
- 제목은 **검색어 기준** (인스타 후킹 제목과 다르게)
