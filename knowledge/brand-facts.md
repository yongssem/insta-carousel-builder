## 디자인 DNA (교체 권장)

### 표기 고정값 (푸터/헤더 — 지어내지 말 것)

AI 가 브랜드명을 지어내는 사고가 있었으므로 **아래 문자열을 그대로** 씁니다.
`templates/slides.v5.*.json` 의 `meta` 가 SSOT:

| 위치 | 값 |
|:---|:---|
| 푸터 좌측 | `@yongssam.dev` + 표시이름 `바이브용샘` (같은 줄, 이름은 위계 낮게) |
| 푸터 우측 | `무궁무진클래스` |
| 상단 헤더 | `— 바이브용샘 diary EP.NN` |

### swipe 문구 (커버/본문 하단)

**뜻이 모호한 조어를 만들지 말 것.** `knowledge/banned-words.json` 의
`swipe_approved` 에서만 고릅니다.

- 커버: `지금 확인하기` / `하나씩 확인하기` / `바로 확인하기`
- 본문: `계속 보기` / `이어서 보기`
- 마지막 직전: `마지막 장`

❌ 금지 예: `판세 보기` — 무엇을 보라는 건지 안 읽힙니다.

### 현재 기본: v5 — 웜 크림 에디토리얼 (다이어리)

캐러셀 기본 스타일입니다. `templates/slides.v5.*.json` 의 `theme` 가 SSOT:

- **배경**: `#F1E9DE` (웜 크림) — 캐릭터 자산 배경과 동일해야 이음매가 안 보임
- **본문 텍스트**: `#1A1A1A` / **약한 텍스트**: `#A0968A`
- **액센트**: `#E1502A` (오렌지레드) — 라벨/룰/강조 키워드/CTA
- **카드**: `#EBE1D3`, 테두리 `#DCD1C1`, 트랙 `#E3D8C7`
- **폰트**: Pretendard 800 헤드라인(60px, 자간 -0.035em) + `swipe to read` 만 serif italic
- **시그니처**: 상단 `— <브랜드> diary EP.NN` / `01 — 09`, 배경 고스트 넘버,
  라벨 뒤 `◆`, 헤드라인 아래 오렌지 룰, 하단 `@핸들` + `스튜디오명`
- **캐릭터**: 슬라이드당 **1명만**, 우측 하단. `assets/characters/*.png`
- **해상도**: **1080×1350 고정**

### 이전: v4 — 다크 테크 에디토리얼 (보관)

`docs/sample-html/` 에 샘플이 남아 있습니다. 다크 톤이 필요할 때 참조:

- **배경**: `#0B0B0E` (deep black) + 액센트 radial glow 1개 + 필름 그레인 오버레이 `← 본인 컬러로`
- **메인 액센트**: `#CF5C3F` (warm orange), 밝은 틴트 `#F0956B`/`#E98A63` 와 그라디언트로 사용 `← 본인 컬러로`
- **액센트 그라디언트**: `linear-gradient(115deg,#F0956B 10%,#CF5C3F 85%)` (헤드라인 키워드/진행 바/CTA)
- **메인 텍스트**: `#FFFFFF` (pure white)
- **서브 텍스트**: `rgba(255,255,255,0.45)` / 캡션 `rgba(255,255,255,0.35)`
- **헤어라인/카드**: `border: rgba(255,255,255,0.09)` + `background: rgba(255,255,255,0.035)`, radius 24px
- **폰트**: Pretendard-like Korean sans-serif / 대형 bold 헤드라인 (Cover 96px/900, 본문 56px/800, 자간 -0.025em) + monospace 는 코드·숫자 전용 (한글 금지)
- **시그니처 요소**: 필 라벨 칩, 배경 고스트 아웃라인 넘버, 상단 진행 바, 하단 푸터(브랜드 + 페이지 번호)
- **레이아웃 철학**: 여백 크게, 좌측 정렬, 트렌디 매거진 에디토리얼 feel
- **해상도**: **1080×1350 고정** (인스타 캐러셀 4:5, 바꾸지 말 것)
