## 0. 먼저 — 선별 기준이 출처보다 중요합니다

AI 뉴스는 하루에 수백 건 쏟아지는데, **교사에게 의미 있는 건 그중 1~2%**입니다.
출처를 늘리기 전에 걸러내는 기준부터 세워야 합니다.

### 통과 조건 — "내일 교실 테스트"

> **이 소식 때문에 내일(또는 이번 학기) 교실에서 뭔가 달라지는가?**

달라지는 게 없으면 아무리 큰 뉴스여도 버립니다.

| 교사가 반응하는 것 | 교사가 반응 안 하는 것 |
|:---|:---|
| 평가·과제 정책이 바뀜 (AI 사용 허용 범위, 표절 판정) | 모델 벤치마크 점수 경신 |
| 학생 안전·개인정보 이슈 | 기업 투자 유치·밸류에이션 |
| 교육청·교육부 지침, 연수 의무화 | 개발자용 API 업데이트 |
| 무료로 쓸 수 있게 된 도구 | 유료 엔터프라이즈 기능 |
| 다른 교사가 실제로 해본 사례 | "AI가 세상을 바꾼다" 류 전망 |
| 업무 경감에 바로 쓰이는 기능 | 파라미터·아키텍처 이야기 |

### 소재 점수표 (5점 이상만 캐러셀행)

| 항목 | 배점 | 확인 |
|:---|:---:|:---|
| 내일 교실 테스트 통과 | 3 | 안 되면 **탈락** |
| 1차 출처가 있음 (기관 발표·논문·공식 블로그) | 2 | 블로그 재인용만 있으면 0점 |
| 국내 교사에게 적용 가능 | 2 | 미국 주법(州法) 같은 건 감점 |
| 아직 다들 안 다룸 | 1 | 이미 포화면 0점 |
| 숫자로 보여줄 수 있음 | 1 | 캐러셀은 시각화가 강점 |
| 내 경험과 붙일 수 있음 | 1 | 163개 앱·18년 현장 |

**5점 미만이면 만들지 마세요.** 억지로 만든 편이 계정 신뢰를 깎습니다.

### ⭐ 라이트 소재 — 툴 업데이트 (주력 소재원)

**가장 자주 쓸 소재는 여기서 나옵니다.** 구독료 변경 · 새 모델 출시 · 새 기능.
정책 뉴스보다 가볍고, 독자가 바로 써먹을 수 있고, 매주 반드시 뭔가 나옵니다.

| 툴 | 체인지로그 / 공지 | 볼 것 |
|:---|:---|:---|
| **클로드 코드** | [code.claude.com/docs/en/changelog](https://code.claude.com/docs/en/changelog) | 버전별 신기능. 교사가 쓸 만한 것만 골라내기 |
| **Anthropic** | [anthropic.com/news](https://www.anthropic.com/news) · [요금제](https://www.anthropic.com/pricing) | 모델 출시, 구독료·사용량 정책 변경 |
| **OpenAI / Codex** | [openai.com/news](https://openai.com/news/) | 모델 출시, 요금제 변경 |
| **Lovable** | 공식 사이트 체인지로그 / 블로그 | 노코드 쪽 신기능 — 교사 진입장벽과 직결 |
| **Google Gemini** | [blog.google/technology/ai](https://blog.google/technology/ai/) | 무료 티어 변화가 특히 중요 |

**툴 소식 고르는 기준** (일반 기준에 더해):

| 쓸 것 | 버릴 것 |
|:---|:---|
| 무료로 풀린 기능 | 엔터프라이즈 전용 기능 |
| 구독료·사용량 한도 변경 | 마이너 버그픽스 |
| 비개발자도 쓰는 기능 (음성, 파일, 웹) | CLI 플래그·API 파라미터 |
| 한국어 성능·지원 변화 | 영어권 전용 기능 |
| "이제 이것도 만들 수 있다" | 벤치마크 점수 |

⚠️ **구독료 이야기는 반응이 제일 좋지만 제일 위험합니다.** 요금제는 국가·시점별로
다르고 자주 바뀝니다. 반드시 **공식 요금 페이지 원문 + 확인 날짜**를 함께 기록하고,
캐러셀에 "2026년 8월 기준" 같은 시점을 명시하세요.

## 2. 2차 출처 — 소재 발견용 (인용은 금지)

여기서 **찾기만** 하고, 숫자는 반드시 1차 출처로 거슬러 올라가 확인합니다.

- 인디스쿨 등 교사 커뮤니티 — 지금 교사들이 실제로 뭘 궁금해하는지
- 네이버 카페·밴드 교사 모임 — 현장 언어 채집
- 해커뉴스 / 요즘IT / GeekNews — 기술 동향 조기 감지
- 인스타 경쟁 계정 — **다룬 걸 피하려고** 봅니다 (따라 하려고가 아니라)

## 3. 주간 루틴 — 30분이면 충분합니다

매일 볼 필요 없습니다. 주 1회 몰아서 봅니다.

1. **10분 · 국내 먼저** — KERIS 새 브리프, 교육부 보도자료 훑기
   → 국내 정책 변화가 가장 확실한 소재입니다
2. **10분 · 해외 통계** — Stanford HAI, EdWeek 헤드라인만
   → 새 수치가 나왔으면 저장
3. **5분 · 도구 변화** — Anthropic/OpenAI/Google 릴리스에서
   "교사가 무료로 쓸 수 있게 된 것"만 골라내기
4. **5분 · 점수 매기기** — 위 점수표로 후보 3~5개 채점, 5점 이상만 남김

남은 후보는 `knowledge/reference/backlog.md` 에 쌓아두고,
캐러셀 만들 때 그중에서 고릅니다. **매번 새로 찾지 마세요.**

## 4. 이 계정만의 각도 — 남들과 같은 뉴스를 다르게

같은 뉴스를 다뤄도 이 계정은 이렇게 비틉니다:

| 일반 계정 | 이 계정 |
|:---|:---|
| "GPT-5 출시" | "그래서 우리 반 앱 만들 때 뭐가 달라지나" |
| "AI 교육 도입률 70%" | "그 70%에 우리 학교가 들어가려면 뭐부터" |
| "AI 표절 논란" | "내 평가 방식은 이번 학기에 어떻게 바꿔야 하나" |

**뉴스를 전달하지 말고, 뉴스를 교실 행동으로 번역하세요.**
18년차 교사가 163개를 만들어 본 경험이 그 번역기입니다. 다른 계정엔 없습니다.
