# carousel-structure.md — 캐러셀 구조 공식

> 한 캐러셀 = 1 Cover + 7 본문 + 1 Outro + **1 엔드카드(책 홍보 고정)** = 10장.
> 주제가 바뀌어도 이 구조는 유지. 프롬프트 내용만 교체.
>
> **10장인 이유**: 7~10장이 완독률·체류시간 스위트스팟이고 12장 초과 시 완독률 약 40% 하락(2026 실측).
> 엔드카드는 Outro를 **대체하지 않고 뒤에 붙습니다** — 저장 CTA를 잃지 않기 위함.

---

## 9장 역할 분배

| # | 역할 | 목적 | 시간 비중 (사용자 체류) |
|:---:|:---|:---|:---:|
| 1 | **Cover** | 3초 내 스크롤 멈춤 | 1.5초 |
| 2 | 본문 ① | 핵심 포인트 1 | 2.5초 |
| 3 | 본문 ② | 핵심 포인트 2 | 2.5초 |
| 4 | 본문 ③ | 핵심 포인트 3 (데이터/그래프) | 3.0초 |
| 5 | 본문 ④ | 핵심 포인트 4 (반전/대조) | 3.0초 |
| 6 | 본문 ⑤ | 핵심 포인트 5 | 2.5초 |
| 7 | 본문 ⑥ | 핵심 포인트 6 | 2.5초 |
| 8 | 본문 ⑦ | 핵심 포인트 7 (클라이맥스) | 3.0초 |
| 9 | **Outro** | CTA (저장/공유/팔로우) | 2.0초 |

**평균 체류 시간 합계**: 약 22.5초 (인스타 캐러셀 완독률 60%+ 목표치 기준)

## Cover 공식

| 요소 | 규칙 |
|:---|:---|
| **카테고리 라벨** | 좌측 하단, orange 테두리 **필 칩** + 도트 (예: "● CLAUDE CODE GUIDE") |
| **메인 헤드라인** | 한글 900 웨이트 2줄 완결 (96px급). 1줄은 white, 1줄은 orange **그라디언트** (대조) |
| **언더라인 바** | 헤드라인 아래 짧은 orange 그라디언트 직선 (시각적 앵커) |
| **서브카피** | 회색, "저장 필수", "하나씩 적용해보세요" 류 행동 유도 |
| **고스트 넘버** | 우상단 배경에 아웃라인 숫자 (예: 팁 개수 "07") — 은은하게 |
| **SWIPE 힌트** | 우하단 화살표 칩 (다음 장 유도) |
| **여백** | 캔버스 상단 40% 이상 비워두기 (premium breathing room) |

**안티 패턴**:
- ❌ 헤드라인 3줄 이상 (정보 과다 = 후킹 약화)
- ❌ 여백 없이 꽉 찬 레이아웃 (AI 티 남)
- ❌ 모든 글자 같은 색 (강약 없음)

## 본문 1장당 공식

| 요소 | 규칙 |
|:---|:---|
| **넘버 라벨** | 좌측 상단 orange 필 칩 "● TIP 01" 형식 |
| **고스트 넘버** | 우상단 배경 아웃라인 숫자 "01" (콘텐츠 뒤, 은은하게) |
| **헤드라인** | 한글 2줄 이내 (56px/800). 핵심 키워드 1개만 orange 그라디언트 강조 |
| **시각 요소** | 1개만, 가급적 헤어라인 카드 안에 (트리 / 그리드 / 다이어그램 / 프로그레스 바 등) |
| **보조 캡션** | 회색, 1줄. 헤드라인을 풀어쓰는 게 아니라 **다른 각도** |
| **진행 바 + 푸터** | 상단 진행 바(n/9), 하단 좌 브랜드 / 우 "0n / 09" 페이지 번호 |
| **CTA** | 본문에는 없음 (Outro로 몰아둠) |

## Outro 공식

- 라벨: 필 칩 "● SAVE & SHARE" 또는 "● FOLLOW FOR MORE"
- 헤드라인: "하나씩 적용하면 체감이 확 됩니다" 류 (결과 약속, 키워드 1글자 그라디언트 강조)
- 여백 최대화 (캔버스 60% 이상 empty dark space) + 중앙 글로우로 마무리 무드
- CTA는 1개만 (저장/공유/팔로우 중 택 1) — 액센트 그라디언트 필 버튼 + SVG 아이콘으로 명확하게
- 배경에 고스트 워드 (예: "SAVE") 허용

## 모션 슬라이드 (움직이는 캐러셀)

정적 캐러셀과 **구조는 동일**합니다. 달라지는 건 각 장이 PNG 가 아니라 짧은 MP4 라는 점뿐.

| 요소 | 등장 타이밍 | 이유 |
|:---|:---|:---|
| 헤더 / 푸터 | 0.0s | 프레임을 먼저 잡아줘야 안정감 |
| 라벨 | 0.0s | 무슨 장인지 즉시 |
| 헤드라인 | 0.14s | 핵심 메시지가 두 번째 |
| 오렌지 룰 | 0.42s (좌→우) | 헤드라인을 시각적으로 닫는 동작 |
| 서브카피 / 노트 | 0.56 ~ 0.68s | |
| 캐릭터 | 0.5s (아래에서 위로) | 텍스트와 동시에 오면 시선이 분산됨 |
| 데이터 시각화 | 0.8 ~ 1.1s (막대는 0→값) | **수치가 차오르는 동작이 이 포맷의 핵심** |
| 출처 | 1.5s | 마지막에 조용히 |
| swipe 유도 | 1.15s | 다음 장으로 넘길 준비가 됐을 때 |

**원칙**: 2초 안에 모든 등장이 끝나야 합니다. 캐러셀 1장 체류시간이 2~3초라
그 안에 못 끝나면 사용자는 완성된 화면을 못 보고 넘깁니다. 남은 1~1.5초는 정지 상태로 둡니다.

**반드시 정지해야 합니다.** 캐러셀 영상은 **루프하지 않고 마지막 프레임에서 멈춥니다.**
끝까지 움직이는 요소가 있으면 어정쩡한 자세로 얼어붙습니다.
→ 모든 애니메이션은 **영상 종료 0.4초 전까지 정착**. `animation: ... infinite` **절대 금지.**
(`animate-slides.mjs` 가 인코딩 전에 마지막 0.4초 정지 여부를 자동 검사합니다.)

실측 정착 시점 예: 텍스트+막대 2.10초 / 도트 순차 2.45초 / 캐릭터 부유 2.95초 (영상 3.5초)

**안티 패턴**:
- ❌ `infinite` 루프 애니메이션 — 위 이유로 금지
- ❌ 계속 움직이는 요소 여러 개 (읽기를 방해)
- ❌ 화려한 전환(회전/플립) — 정보형 캐러셀에서는 싸구려로 보임
- ❌ 장마다 다른 등장 순서 (9장이 따로 노는 느낌)

## 엔드카드 공식 (slide-10, 고정)

- **내용 고정**: 책 홍보 이미지 1장. 주제와 무관하게 **모든 캐러셀에 동일하게** 붙음
- **생성하지 않음**: `assets/book-promo-endcard.png` 원본을 `scripts/make-endcard.js` 가 4:5로 맞추기만 함
- **비율 주의**: 인스타는 한 게시물의 모든 장이 같은 비율이어야 함.
  원본이 1:1이면 4:5 캔버스 중앙에 배치하고 위아래를 `#0B0B0E` 로 채움 (잘림 방지)
- **캡션과 세트**: 캡션 하단 책 홍보 블록(구매 링크)과 항상 함께 나감

## 7가지 본문 구조 (주제별 선택)

| 구조 | 적합한 주제 예시 |
|:---|:---|
| **팁 나열** (TIP 01~07) | "Claude Code 7가지 꿀팁", "블로그 SEO 5원칙" |
| **단계별** (STEP 1~7) | "AI 자동화 5단계", "브랜드 런칭 7단계" |
| **Before/After** | "AI 쓰기 전후 비교 7가지" |
| **질문-답변** (Q&A 7개) | "AI 초보 자주 묻는 질문" |
| **비교** (A vs B ×7) | "ChatGPT vs Claude 실전 비교" |
| **통념 깨기** (통념→사실 ×7) | "AI에 대한 착각 7가지" |
| **체크리스트** (√ 7항목) | "런칭 전 점검해야 할 7가지" |

## 한글 렌더링 팁 (실측 기반)

- Gemini 3.0 Pro Image는 한글 **짧은 단어** (2~4글자) 에서 99%+ 정확
- **5글자 이상 전문용어** (예: "컨벤션") 또는 **받침 복잡한 단어** (예: "멍렁어") 에서 오타 위험
- 대응: 해당 슬라이드에 한글이 많을 경우 → 프롬프트에 해당 단어를 명시적으로 따옴표로 묶고 spelling 강조
- 오타 발생 시: 해당 슬라이드만 `--only slide-XX` 로 재생성 (미구현, 현재는 전체 재생성)
