# reels-format.md — 릴스 산출물 형식 (SSOT)

> 릴스를 만들 때 **항상 두 벌**로 냅니다. 하나로 합치지 마세요.

---

## 산출물 두 벌

| 파일 | 무엇 | 누가 읽나 |
|:---|:---|:---|
| `reels-<길이>.md` | **기획서** — 시간대별 화면·연출 의도·촬영 체크 | 사람 (촬영·편집 판단용) |
| `reels-<길이>.srt` | **자막** — 타임코드 + 문구만 | 편집 프로그램 |

**자막을 마크다운 안에 목록으로 넣지 마세요.** 편집기에 못 얹습니다.
기획서 표는 연출 참고용이고, **자막의 기준은 언제나 srt** 입니다.
둘이 어긋나면 srt 가 맞습니다. 문구 수정도 srt 에서 합니다.

---

## SRT 작성 규칙

```
1
00:00:00,300 --> 00:00:02,150
우리가 졌던 전투입니다

2
00:00:02,300 --> 00:00:03,900
여기선 이깁니다
```

- 번호는 **1부터 빈틈없이**. 건너뛰면 일부 편집기가 뒤 자막을 버립니다
- 타임코드는 `시:분:초,밀리초` — **소수점이 아니라 쉼표**입니다
- 화살표는 ` --> ` (앞뒤 공백 필수)
- 큐 사이는 **빈 줄 하나**. 마지막 큐 뒤에도 줄바꿈 하나
- 인코딩 **UTF-8**. BOM 없이
- 큐끼리 **겹치지 않게**. 0.1초 정도 간격을 둡니다
- 한 큐는 **최대 두 줄**. 세 줄부터는 폰에서 화면을 가립니다
- 줄바꿈은 문장 의미 단위로 (`이름 정하고` / `그림 열 장이면 끝`)

### 길이 감각

| 자막 길이 | 최소 노출 |
|:---|:---|
| ~8자 | 1.2초 |
| 9~15자 | 1.8초 |
| 16자 이상 | 2.5초 |

읽을 시간을 안 주면 자막이 있으나 마나입니다.
**반전·핵심 문구는 3초** 확보하세요.

## 내보내기 전 검증

숫자·타임코드를 손으로 고치면 반드시 깨집니다. 아래로 확인하세요.

```bash
python3 - <<'PY'
import re
p='output/<topic>/reels-25s.srt'
blocks=[b for b in re.split(r'\n\s*\n', open(p,encoding='utf-8').read().strip()) if b.strip()]
def sec(t):
    h,m,rest=t.split(':'); s,ms=rest.split(',')
    return int(h)*3600+int(m)*60+int(s)+int(ms)/1000
prev=0
for i,b in enumerate(blocks,1):
    L=b.split('\n')
    assert L[0].strip()==str(i), f'번호 오류 {L[0]}'
    m=re.match(r'^(\d{2}:\d{2}:\d{2},\d{3}) --> (\d{2}:\d{2}:\d{2},\d{3})$', L[1])
    assert m, f'타임코드 오류 {L[1]}'
    st,en=sec(m.group(1)),sec(m.group(2))
    assert en>st, f'{i}번 길이 0'
    assert st>=prev, f'{i}번 겹침'
    prev=en
print('OK', len(blocks),'큐 /', prev,'초')
PY
```

## 불러오는 법 (사용자 안내용)

- 프리미어 — `파일 → 가져오기`
- 캡컷 — `자막 → 로컬 자막 가져오기`
- 다빈치 리졸브 — 미디어 풀에 드래그
- 브루(Vrew) — `자막 → 파일에서 불러오기`

## 인스타 릴스 주의

- **음소거 자동재생**이 많습니다. 자막 없이 이해되는 릴스는 없다고 보세요
- 자막은 **화면 중앙~상단**. 하단은 인스타 UI(계정명·캡션·버튼)에 가립니다
- 인스타 자동 자막에 맡기지 마세요. 한국어 오인식이 잦고 위치도 못 잡습니다
- srt 를 얹은 뒤 **소리를 끄고 한 번 돌려보기** — 이해되면 통과
